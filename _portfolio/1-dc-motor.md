## Goal
Design and build a working DC motor from CAD, using only readily available materials.

## Challenges
Early versions had inconsistent brush contact with the commutator, which made performance unreliable.

## Solution & Results
- Iterated through **three design revisions**
- Added **adjustable brush position and tension**, which fixed the contact problem
- The only motor in the class to handle **over 20 V** (next highest: 7 V)
- Now used as an example for future classes
